# Source of Truth: Matlab Lineage

## Current source files

### Measurement stage
- `MeasureSine14.m`

This is the primary source of truth for:
- WAV ingest
- envelope detection
- snippet extraction
- lag extraction
- frequency estimation
- harmonic estimation
- measurement artifact generation

### Compile stage
- `CompileSine24.m`

This is the current source of truth for:
- post-measurement fitting
- radius reconstruction
- smoothing
- stylus LR / stylus yaw fit
- distortion modeling
- sweep fitting across mount yaw

### Historical compile stage
- `CompileSine23.m`

Keep for history only. Python compile logic should now be checked against `CompileSine24.m` first.

## Important execution order
The Matlab flow is:
1. `MeasureSine14.m`
2. `CompileSine24.m`

`CompileSine24.m` is **not** a preprocessing step for `MeasureSine14.m`.
It consumes the measurement outputs generated by the measurement stage.
